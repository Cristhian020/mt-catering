# Fotos de eventos

Cada **carpeta** dentro de `eventos/` es un evento de la galería de la web.

## Cómo agregar un evento

1. En tu computadora crea una carpeta con **la fecha y el nombre del evento**, así:

   ```
   2026-11-15 Almuerzo Banco Popular
   ```

   (año-mes-día, un espacio y el nombre). La fecha sirve para ordenar: el evento más reciente sale primero y en grande.

2. Mete dentro las fotos del evento (JPG o PNG, como salen del celular; no hace falta achicarlas).
   Si quieres elegir la foto de portada, llámala `portada.jpg`. Si no, se usa la primera.

3. Entra a esta página y **arrastra la carpeta completa**:
   <https://github.com/Cristhian020/mt-catering/upload/main/eventos>

4. Abajo pulsa **Commit changes**.

En 2 o 3 minutos el evento aparece en la web, en la sección **Galería**.

## Agregar fotos a un evento que ya existe
Abre la carpeta del evento aquí en GitHub → **Add file → Upload files** → arrastra las fotos → **Commit changes**.

## Borrar una foto o un evento
Abre la foto → menú **···** → **Delete file** → **Commit changes**.
Para borrar un evento completo, borra todas sus fotos.

## Consejos
- Mejor fotos horizontales o cuadradas para la portada.
- Evita fotos donde se vean datos privados de clientes o documentos.
- Si el cliente no quiere que se publique su nombre, pon un nombre general: `2026-11-15 Almuerzo corporativo`.
